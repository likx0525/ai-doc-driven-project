- 不允许只写“加个页面”就直接开发。

- UI 不承载核心业务规则。
- UI 文案变化如果影响用户理解，必须同步更新 `USER_MANUAL.md`。
- 页面状态必须覆盖空状态、错误状态和加载状态。
