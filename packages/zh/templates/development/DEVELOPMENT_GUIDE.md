## 多会话 Git 协作建议

1. 每个 AI 会话应使用独立分支。
2. 分支名建议包含任务编号和会话编号。
3. 开始前检查 `git status`。
4. 修改前拉取最新状态。
5. 提交前检查 `git diff`。
6. 合并前解决冲突。
7. 不在未确认情况下强制覆盖远端变更。

分支命名示例：

- `ai/T-003-S-20260518-001`
- `ai/audit-S-20260518-002`
- `ai/docs-manual-S-20260518-003`

提交信息示例：

```text
[T-003][S-20260518-001] update user flow changeset
```
