# artifacts

> 文档状态：current

## 目录用途

- `screenshots/`：截图。
- `reports/`：测试报告、阶段报告、问题报告、接管报告。
- `analysis/`：需求分析、问题分析、架构分析、数据模型分析。
- `prototypes/`：原型说明、实验性设计、方案草案。
- `temp/`：临时材料，可定期清理。

## 命名规则

- `YYYYMMDD-编号-主题-说明.md`
- `YYYYMMDD-编号-主题-说明.png`
- `YYYYMMDD-任务编号-说明.md`

## 引用规则

每个产物必须至少被以下文档之一引用：

- `docs/ai-dev/tasks.md`
- `docs/ai-dev/feedback.md`
- `docs/ai-dev/decisions.md`
- `docs/ai-dev/PROJECT_AUDIT.md`
- `docs/test/test-runs.md`
- `docs/artifacts/ARTIFACTS.md`

禁止产生无人引用的孤立文件。

## 敏感信息

截图、报告、分析材料和临时文件不得包含真实密钥、真实 token、真实密码、真实 cookie 或真实用户隐私数据。
